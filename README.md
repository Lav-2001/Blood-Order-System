# Blood-Order-System
BloodConnect is a web-based Blood Order Management System designed to help users find available blood banks and place blood orders easily.

The project currently contains the frontend interface for receivers. It includes pages for user registration, login, dashboard, blood bank listing, placing blood orders, viewing orders, order details, and user profile.

# Features
- User Registration
- User Login
- Receiver Dashboard
- Blood Bank List
- Search and Filter Blood Banks
- Place Blood Order
- View My Orders
- View Order Details
- Cancel Order
- User Profile
- Responsive Design
- Simple and user-friendly interface
# Technologies Used

- JavaScript

# How to Run
1. Clone the repository:
- git clone(https://github.com/Lav-2001/Blood-Order-System.git)
2. Open the project folder:
- cd BloodConnect
3. Open index.html in a web browser.
- You can also use VS Code Live Server to run the project.
